### 📑 Funcionalidades del Menú General

En este menú, el usuario podrá realizar y generar las siguientes actividades clave:

✅ **Dinámicas y procesos generales:**

Recepción de fruta.
Generar despachos.
Inventarios.
Seguimientos de pallets (auditorías incluidas).
Generar informes dinámicos de existencias diarias:
El usuario puede seleccionar el tipo de informe:

🔹 **Mixto**  
🔹 **Sin carácter mixto**

✅ **Módulo SAG:**

Mantener reportes del SAG.
Gestionar inspectores encargados.
Configurar despachos SAG y otros ajustes.

✅ **Otros controles importantes:**

Mantener control de fumigación.
Generar la planilla de control de temperatura.
